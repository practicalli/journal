    A new Clojure Terminal REPL under development

    I had a quick test of the Clojure CLI REPL on a simple Practicalli project, comparing the experience with my current preference of Rebel Readine.

    Clojure CLI has an interesting Inspector feature and the ability to evaluate part of an expression. A config file should be added to define key mappings for these features (no key mappings by default, but there is an example config and docs to help).

    I hope the project simplifies the paths for the config file (reduce the verbosity), to make working with the project more accessible. It does honour the Clojure CLI config location, which is excellent.

    There is a lot of promise to the Clojure CLI REPL, but for my workflow (and without tab completion of namespace and function names) its not ready to be a replacement for Rebel Readline (yet).

    I will keep a lookout for updates to this project though and continue testing.

    For day to day work I will continue using Rebel Readline as my Terminal REPL prompt

    Practicalli Rebel Readline Terminal REPL prompt

    Practicalliλ︎

    I am trying out the Clojure CLI REPL is a new project to provide a rich command line REPL support, using Java Jline.

    Features: - multi-line editing - bracket highlighting - structural editing - inline eval - doc lookup for Clojure and Java - a data inspector - configurable prompts - custom keybindings - Vim or Emacs editing modes

    I've added aliases to Practicalli Clojure CLI Config using my standard naming convention:

    • :repl/cli start nREPL server and rich REPL client
    • :repl/serve start nREPL server only
    • :repl/attach start a client and attach to an existing nREPL server

    The nREPL server creates an .nrepl.port file containing the local port the nREPL server is listening too

    Startupλ︎

    The aliases were added to the Clojure user level configuration $XDG_CONFIG_HOME/clojure/deps.edn

    The XDG_CONFIG_HOME environment variable was checked that it still points to the correct location.

    ❯ echo $XDG_CONFIG_HOME
/home/practicalli/.config

    Run the nREPL server and client using the Clojure CLI tool.

    clojure -M:repl/cli

    The CLojure CLI REPL did not create a config file, but did create a history buried deep in the path $XDG_CONFIG_HOME/clojure/.cljconf/org.clojure/clojure-cli.repl/

    Its unclear why the config and history need to be on such a deep path when there could be a much simpler

    • history: $XDG_CONFIG_HOME/clojure/cli-repl/history
    • config: $XDG_CONFIG_HOME/clojure/cli-repl/config.edn
    • dependencies: $XDG_CONFIG_HOME/clojure/cli-repl/deps.edn

    Or

    • history: $XDG_CONFIG_HOME/clojure/history
    • config: $XDG_CONFIG_HOME/clojure/cli-repl-config.edn
    • dependencies: $XDG_CONFIG_HOME/clojure/cli-repl-deps.edn

    NOTE: it felt confusing to have a .cljconf dotfile within the parent .clojure dotfile, especially when the Clojure CLI config is in $HOME/.config/clojure/.cljconf. I missed that this had been created at first.

    The .cljconf name could easily be mistaken for something related to Clojure CLI rather than Clojure CLI REPL.

    The Clojure CLI REPL honours the Clojure CLI location. It did not try to create a $HOME/.clojure directory, which is good as I dont use that classic approach to dotfiles. I checked as the Clojure CLI REPL docs only mention ~/.clojure as the config directory.

    First useλ︎

    I could evaluate expressions and multi-line typing worked.

    (map
 inc
 [1 2 3 4 5])

    History of expressions is accessed via the Up arrow Up or via Ctrl r and typing a pattern (just like the usual shell history search)

    I did not get docs after pausing at the end of a function name. I didnt realise initially that a configuration file with key mappings is required to make some features work.

    Because the key mappings were not at hand, I didnt know how to do structural editing, editing a multi-line expression, call docs or inspect a result).

    Ctrl d to exit the REPL prompt back to the shell prompt. I first evaluated (quit), (exit), :quit, :exit to see if they would exit the REPL, but without success.

    Its a new project, so just a little bit of docs or hunting through the code should fix that challenge. I wonder if the Clojure CLI REPL project will be part of a demo at the Clojure Conj this week?

    Inspectorλ︎

    I started by evaluating a basic expression

    (map inc [1 2 3 4 5])

    Then use M-i to inspect the result

    *1  LazySeq · 5 items

0 · 2
1 · 3
2 · 4

4 · 6

1-5 of 5  ←↓↑→/hjkl navigate · d def · q quit

    The inspector shows each index and value from the sequence that was returned as the result of the evaluation.

    Results that return a nested map are much more interesting though.
