### Kitty

Adding key mappings to kitty to support my Zensical workflow, where I run the local server in a separate terminal window underneath the main editor window.

!!! EXAMPLE "Linux specific key mappings for Kitty"
    ```config
    # ---------------------------------------------------------
    # Key mappings

    # Ctrl + Shift + Arrow up/down moves between kitty tabs

    # Open new tab in current window
    map ctrl+shift+t launch --cwd=current --type=tab --location=neighbor

    # Open short window as horizontal split in current window
    map ctrl+shift+enter launch --cwd=current --type=window --location=hsplit --bias=20

    # Switch window split focus
    map ctrl+up neighboring_window up
    map ctrl+down neighboring_window down

    # Resize window splits
    map ctrl+shift+j resize_window shorter 3
    map ctrl+shift+k resize_window taller 3
    map ctrl+shift+h resize_window narrower
    map ctrl+shift+l resize_window wider

    # reset all windows in the tab to default sizes
    map ctrl+shift+home resize_window reset
    # ---------------------------------------------------------
    ```
