## London Clojurians

Agreed to manage the Clojure Meetup Pilot sponsorship for the London Clojurians.

Payment is via GitHub Sponsors in USD. A transfer needs to be made each month, around the 22nd, to the London Clojurians Open Collective account (GBP).

One approach is to create a one-off payment on Open Collective each month and send a bank transfer from the Wise account used to receive GitHub sponsorship.

GitHub sponsors typically pays out around the 22nd of each month (give or take a day).

Initially the 100 USD I would receive in my Wise USD account would be sent using a bank transfer to the GBP bank account, creating a contribution via the London Clourians Open Collective page for transfer details and reference.

If the Clojure Meetup Pilot extends beyond the 6 month pilot I would set up a regular direct debit payment on Open Collective using a typical exchange rate (adjusting if that rate varies significantly).

As an example, at today's exchange rate it would result in a payment of 74.48 GBP, minus 3.75 London Clojurians fiscal host fee, for a total of 70.73 GBP.

So expect a payment of around 70 GBP toward the end of each month once the Clojure Meetup Programme has been set up for our community.
