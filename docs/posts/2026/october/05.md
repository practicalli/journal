## Clojure

There are some new developments in the tools aspect of Clojure CLI. The underlying change is the tools.deps.? library which supports declarative and programatic configuration (build also has programatic config, which I havent used above the basics).

I havent used tools as installed tools, only using these tools via aliases.

The Clojure CLI Config uses the `-T` flag for a couple of projects, e.g. liquidz/antq and seancorfield/deps-new.

I assume the new features are to help tool developers, enabling greater customisation and programatic configuration.

I currently have no use cases for why I would need programmatic configuration for the few tools I use.

I find it jaring that there is a double dotfiles path too. This feels like it goes against config naming conventions. It also makes my gitignore 'inclusive patterns' approach fail 😞

If I think of a use then I'll carve out some time to investigate.

If the Rebel Readline project ever stops working I'll try the Clojure CLI REPL tool again.
