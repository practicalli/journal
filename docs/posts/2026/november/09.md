## Practicalli

### Blog and Journal

Updated the date format in all posts to use the `date: created: updated:` frontmatter syntax, to ensure the Zensical RSS feed for the websites is created in the correct date order.

Older posts using the `date: <yyyy-mm-dd>` syntax have the wrong date assigned to them during build, as Practicalli website configuration for Zensical looks for values in `created:` and `updated:`.

It is assumed that the single `date:` format frontmatter syntax prevents the zensical plugin from finding the `current:` date value, so it uses the date of the build.

A macro was defined in Neovim to change from the simple `date:` syntax to the `date: created: updated:` syntax.

On the [practicalli-johnny/practicalli-johnny repository](https://github.com/practicalli-johnny/practicalli-johnny){target=_blank}, created a "Repository Secret" called `SUMMARY_CARDS_TOKEN`, using the value of the personal access token.

Updated the `GitHub-Profile-Summary-Cards` to only use the `dark` theme, to only generate that specific theme (generates all themes by default).

Switched to the `ubuntu-slim` image to run the action upon (from `ubuntu-latest`), to save a little time in downloading the image during the workflow run.

Updated actions/checkout to version 7 to support latest node.js version available in GitHub actions.

```yaml
name: GitHub-Profile-Summary-Cards

on:
  schedule: # execute every 24 hours
    - cron: "* */24 * * *"
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-slim
    name: github-profile-summary-cards
    permissions:
      contents: write

    steps:
      - uses: actions/checkout@v7
      - uses: vn7n24fzkq/github-profile-summary-cards@release
        env: # create an Actions personal access token called `SUMMARY_CARDS_TOKEN`
          GITHUB_TOKEN: ${{ secrets.SUMMARY_CARDS_TOKEN }}
        with:
          USERNAME: ${{ github.repository_owner }}
          # BRANCH_NAME is optional, default to main, branch name to push cards
          BRANCH_NAME: "main"
          # THEME to generate only specified theme, default `""` generates every theme
          THEME: "dark"
          # UTC_OFFSET is optional, default to zero
          # UTC_OFFSET: 1
          # EXCLUDE is an optional comma seperated list of languages to exclude, defaults to ""
          EXCLUDE: "JavaScript,CSS,Java,Makefile,HTML,C++"
```
