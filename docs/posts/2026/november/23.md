## Debian Linux

Updated the [language/clojure.sh]() install script to prompt the user if they wish to [install the Practicalli Clojure CLI Config](){target=_blank}

If the Clojure config directory is a symbolic link, the assumption is that the install (git clone) of the Practicalli config should be skipped (and exits the script).

!!! EXAMPLE "Bash: determine location of Clojure Config"
    ```shell
    echo "Practicalli Clojure CLI Config"

    echo "Check location of existing config (exit script if symbolic link found)"
    if [[ -L "$XDG_CONFIG_HOME"/clojure ]]; then
      echo "Practicalli Clojure CLI set via a symbolic link - all set"
      exit 0
    elif [[ -L "$HOME"/.clojure ]]; then
      echo "Practicalli Clojure CLI set via a symbolic link - all set"
      exit 0
    elif [ -d "$XDG_CONFIG_HOME"/clojure ]; then
      clojure_config_dir="$XDG_CONFIG_HOME"/clojure
    elif [ -d "$HOME"/.clojure ]; then
      clojure_config_dir="$HOME"/.clojure
    else
      echo "No Clojure CLI Config found"
      clojure_config_dir=
    fi
    echo
    ```

Neovim 0.13 should be release on 25 November 2026.

New features in Neovim 0.13 release.

- Native multiple cursors
- Persistent Neovim sessions with `:detach!` and `:connect`
- Real-time external file detection via file system watchers
- Structured concurrency with `vim.async`
- Improved built-in LSP completion
- Image rendering with `vim.ui.img`
- A redesigned command-line window
- Additional built-in plugin management features
- Treesitter performance improvements
- Updated undo behavior
- Lua functions directly usable as option values
- Experimental Web Assembly build (via Zig)

### Multiple cursors

I have been using `vim-visual-multi` plugin successfully to wrangle text with multiple cursors.

- create a list / table from multiple consecutive lines
- indent code blocks and python markdown annotations
- search for a pattern and place a cursor on each match

Neovim 0.13 has native multiple cursor support.

`Q` now creates a multiple cursor instead of replaying the last recorded register.

- `Q` Add or remove a cursor
- `[count]Q` Add cursors to search matches
- ++ctrl+arrow-left++  Toggle a cursor with the mouse
- `q=` Toggle follow mode
- ++ctrl+"L"++ Clear cursors
- `gQ` Restore cleared cursors


Lua API: `vim.api.nvim_mcursor()`


??? EXAMPLE "Reset Q mapping behaviour"
    ```lua
    vim.keymap.set('n', 'Q', function()
      local reg = vim.fn.reg_recorded()

      return reg == '' and '' or ('@' .. reg)
    end, { expr = true })
    ```

## Financial

Listened to a pension webinar on "How much do you need to retire?"

Planning for a comfortable retirement is a long term plan. It doesnt need to be detailed and a little effort infrequently can ensure a healthy pension when you do plan to retire.

Identify how much you need your pension to support when you retire. Group your expected expenditure to better understand how much is really needed.

1. Cost of existence (food, bills, etc) - the minimum
2. Cost of living (hobbies, holidays, family, etc)
3. Bucket list spending

Each of these costs can vary quite differently between people.

These costs should be revisited every year or if there is a significant life event (more often as you get closer to retirement).

Costs will increase due to inflation, although each kind of cost may increase by quite different percentage levels.

### Sustainability

Consider how the pension will last through retirement.

The 4% rule is one general approach where you take only 4% of your pension each year. Growth of the pension should offset the

Four box principle - diversifying where income is generated from (there are more than 4)

- Cash / Savings (long term savings accounts give ~5% interest - with 1,000 GBP tax free )
- Pensions (tax free lump sum, )
- Bonds ?
- ISA (tax free savings)
- Shares (capital gains tax allowance)
- Property (own house can be sold tax free - downsizing can reduce running costs)


!!! TIP "Convert Pension Lump sum to Long term savings"
    Up to 25% of a retirement pot can be withdrawn and placed into longer term savings, ISA, shares, etc.

    Current offerings are around 5% interest, especially for 5 year pots.


!!! TIP "Shares should not be depended upon"
    The value of shares can go down at unknown times, potentially loosing significant amount of money.

    Do not invest money you will depend on in the short term, as this greatly increases risk.

    Invetst only monies that wont be required in the next year and regularly check the value of shares if there is a greater risk that


### State Pension

Understand how much state pension you can claim (and if you can claim it).

State pension is based on number of years making National Insurance contributions (NI) via the PAYE or as a self-employed.

> Suggestion: avoid rely solely on the state pension if possible. If you do not have personal pension, review saving schemes from banks, ISA and government bonds to make the most of the money you do have.


### Tax allowances

A state pension alone should not incur a tax penalty, although this may change in the future (government policy dependant).

Personal pension is likely to incur basic rate of tax.

Taking the full tax free lump sum up front and placing in long term tax savings can reduce the overall tax due.
