### Proselint

Diacritic marks are added a letter to show how a word should be pronounced, e.g. Cafe.

I do not use many words that have diacritic marks so I updated the Proselint config to switch off the check for `diacritical_marks` from the typography section.


```config
{
  "checks": {
    "annotations": false,
    "lexical_illusions": false,
    "typography.diacritical_marks": false,
    "typography.symbols.curly_quotes": false,
    "typography.symbols.ellipsis": false,
    "typography.punctuation.hyperbole": false
  }
}
```

### Megalinter Clojure custom image

The Checkmake Makefile lint tool has been [disabled from Megalinter for security concerns - trivy detected CVE's](https://github.com/checkmake/checkmake/issues/99){target=_blank}. It seems the CVE's have been resolved by upgrading the version of Go in the Docker build of Checkmake and a new release created.

However, Megalinter has not re-enabled Checkmake linter as of version 10.0.0.

Megalinter does not suggest a replacement on the [removed linters page](https://megalinter.io/latest/removed-linters/){target=_blank}

A search discovered two implementations of a Makefile Language Server (LSP) which may be of more value, especially when editing a Makefile.

- [make-ls](https://github.com/owenrumney/make-ls){target=_blank}
- [makefile-lsp](https://github.com/jelmer/makefile-lsp){target=_blank}

Unfortunately these seem quite early stage projects and are not part of Mason (Neovim) and have basic install instructions. It should be possible to install these projects using the DRA tool, but integration with Neovim and other editors doesnt seem to be there yet.


In the mean time, I am removing `MAKEFILE_CHECKMAKE` linter from the [Practicalli Megalinter Custom Flavor for Clojure](https://github.com/practicalli/megalinter-custom-flavor-clojure){target=_blank}.

The `mega-linter-custom-flavor.yml` file was edited and the `MAKEFILE_CHECKMAKE` line deleted.

Then the Megalinter runner tool was run to update the project files so that Checkmake tool would not be included in the custom flavor.

## Debian Linux

Using the [Debian Linux post install scripts in Practicalli dotfiles](https://github.com/practicalli/dotfiles){target=_blank} I have installed the Mozilla version of the Firefox browser.

The `debian-linux/apps/firefox-deb.sh` script uses the official Mozilla Personal Package Archive (PPA) to install Firefox via the Advanced Package Tool (`apt`).

Debian Linux uses the [Firefox Enterprise Browser](https://www.firefox.com/en-US/browsers/enterprise/) as the default Firefox package, available in the main package repository.

I have had issues using Firefox ESR with sites such as [User Crowd](https://usercrowd.com) where I complete usability testing work.
